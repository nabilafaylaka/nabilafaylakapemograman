Website Musik

Website Musik merupakan proyek tugas mata kuliah yang dibuat menggunakan HTML, CSS, dan JavaScript.

Deskripsi

Website ini menampilkan beberapa pilihan lagu yang dapat diputar oleh pengunjung. Website dilengkapi dengan gambar sampul lagu dan pemutar musik.

Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

Fitur Website

- Menampilkan daftar lagu.
- Memutar musik dalam format MP3.
- Menampilkan gambar sampul lagu.
- Tampilan website dengan desain sederhana dan menarik.

File Repository

- "index.html"
- "style.css"
- "script.js"
- File musik MP3
- File gambar JPG dan PNG

Tujuan

Proyek ini dibuat untuk memenuhi tugas mata kuliah dan menerapkan penggunaan HTML, CSS, serta JavaScript dalam pembuatan website.
